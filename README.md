# Global-GDP-Dashboard-with-Power-BI
Summary of World by GDP" is an interactive Power BI dashboard that visualizes and analyzes global economic and demographic data across countries and continents. Using data from the classic World database (CSV format), this project offers insights into GDP distribution, population patterns, life expectancy, and official languages worldwide.

This project provides an interactive Power BI dashboard that visualizes global economic and demographic data by country and continent using datasets derived from the classic "World" database.

## 📊 Dashboard Objectives

- Analyze GDP by country and continent
- Compare population distribution and life expectancy
- Identify top-performing countries economically
- Explore official languages and regional dynamics
- Provide users with an intuitive and interactive way to explore global data

---

## 🧾 Data Sources

- **Country.csv**: Contains country-level metrics like GDP (GNP), population, life expectancy, etc.
- **City.csv**: Provides city-level data linked to countries.
- **CountryLanguage.csv**: Details languages spoken in each country and whether they are official.

---

## 📁 Project Files

| File | Description |
|------|-------------|
| `Summary of world by GDP.pbix` | Main Power BI dashboard file |
| `Country.csv` | Country-level economic and demographic data |
| `City.csv` | Cities linked to countries |
| `CountryLanguage.csv` | Language distribution by country |

---

## 📌 Key Visuals in the Dashboard

- 🌐 **Global KPIs**: Total GDP, Population, Average Life Expectancy
- 🗺️ **Filled Map**: GDP distribution by country
- 📈 **Bar Chart**: Top 10 GDP countries
- 🌍 **Treemap**: GDP contribution by continent
- 🧾 **Summary Table**: Country-level detail with GDP, population, life expectancy, and languages

---

## 🚀 How to Use

1. Open the `Summary of world by GDP.pbix` file in **Power BI Desktop**
2. Interact with slicers to filter by continent, country, or language
3. Use the reset button to clear selections
4. Analyze trends and export visuals as needed

---

## 🧠 Insights & Findings

- The United States and China have the highest GDP.
- Europe has a high average life expectancy across multiple countries.
- Africa shows high population growth but lower GDP per capita.
- Several countries have multiple official languages, often linked to colonial history.
